OF Block — Settings

Filters spam DMs in your X Message Requests folder. All settings stay on your device. The lists below sync across your signed-in Chrome profiles.

Sensitivity

A thread is filtered when its score crosses this number. Lower = stricter (more things get filtered, more false positives). Higher = lenient.

3

Reveal mode

Choose what happens after you click "Show" on a filtered row.

Allowlist

One handle per line, no @. These senders are never filtered.

Blocklist

One handle per line, no @. These senders are always filtered.

Keywords

One phrase per line, case-insensitive. Matches in message snippets and bios. Leave empty to use the built-in seed list.

Maintenance

Profile cache holds 7 days of bio lookups so we don't re-fetch the same sender. Clear it if filtering feels stale.

How filtering works

  • Numeric handle suffix — handle ends in 4+ digits (e.g. @MJoy90602786).
  • Name/handle mismatch — display name doesn't appear in the handle (recycled accounts).
  • Templated opener — message snippet matches one of your keywords.
  • Placeholder leak — snippet contains a literal [name] the bot didn't fill.
  • Emoji name — display name has decorative emojis (heart, peach, etc.).
  • Bio / link inspection — sender's profile bio mentions OF/keywords, or links to onlyfans / fansly / linktr.ee / beacons.ai. (Borderline cases only.)
  • Mutuals override — "Followed by … you follow" always keeps the row visible.
